# Lite TV — быстрый лаунчер и ускорение Android‑телевизора

* `launcher/` — исходники лаунчера (чистый Android, без библиотек, APK ≈ 40 КБ)
* `tv-tools/` — скрипты: подключиться к ТВ, поставить лаунчер, отключить лишнее; и откат
* `.github/` — автосборка APK на GitHub (ничего ставить на компьютер не нужно)

---

## Шаг 1. Получить APK (один раз)

**Вариант А — через GitHub, без установки программ (≈5 минут):**

1. Зайдите на github.com → **New repository** → любое имя, можно Private → **Create**.
2. На странице репозитория нажмите **uploading an existing file** и перетащите **всё содержимое** папки `LiteTV`, включая папку `.github` → **Commit changes**.
   На macOS папка `.github` скрыта: в Finder нажмите `Cmd + Shift + .`
3. Вкладка **Actions** → сборка запустится сама (если нет: *Build Lite TV APK* → *Run workflow*).
   Через 3–4 минуты откройте сборку → внизу **Artifacts → LiteTV-apk** → скачается zip, внутри `LiteTV.apk`.

**Вариант Б — Android Studio:** *Open* → папка `launcher` → в терминале студии `gradlew assembleRelease` →
файл `launcher/app/build/outputs/apk/release/app-release.apk`.

## Шаг 2. Подготовить телевизор

1. *Настройки → Настройки устройства → Об устройстве* → 7 раз нажмите на **«Сборка»** → «Вы стали разработчиком».
2. *Настройки → Настройки устройства → Для разработчиков* → включите **«Отладка по USB»**
   (и **«Отладка по сети»/ADB over network**, если такой пункт есть).
3. Узнайте IP‑адрес: *Настройки → Сеть и Интернет → ваша сеть*.

> **Google TV / Android 12+**: если подключение не проходит, включите **«Беспроводная отладка»** →
> **«Подключить по коду»** и выполните на компьютере `adb pair IP:порт` (код и порт — с экрана ТВ).
> В скрипте потом введите IP:порт из строки «IP‑адрес и порт».

## Шаг 3. Запустить

**Windows**

1. Скачайте *SDK Platform‑Tools for Windows*: https://developer.android.com/tools/releases/platform-tools
   и распакуйте папку `platform-tools` внутрь `tv-tools`.
2. Положите `LiteTV.apk` в `tv-tools`.
3. Запустите `setup-tv.bat` → введите IP → на ТВ нажмите **«Разрешить»** → выберите режим.

**macOS / Linux**: `brew install android-platform-tools` или `sudo apt install adb`, затем
положите `LiteTV.apk` в `tv-tools` и запустите `bash setup-tv.sh`.

### Что делает скрипт

* сохраняет список всех приложений в `tv-tools/backup/`;
* ставит Lite TV, заранее компилирует его (быстрый запуск) и делает главным экраном;
* отключает стандартный главный экран и фоновый мусор — список в `tv/bloat-list.txt`, его можно править;
* ускоряет системные анимации до 0.5×, чистит кеш, перезагружает ТВ.

Режим **1 (безопасный)** не трогает ничего, что нужно для просмотра.
Режим **2 (максимум)** ещё отключает Chromecast, голосовой поиск Google, заставки, Netflix —
выбирайте, только если этим не пользуетесь.

Ничего не удаляется насовсем. **Откат:** `restore-tv.bat` / `bash restore-tv.sh`
(сброс ТВ к заводским настройкам тоже всё вернёт).

## Как пользоваться лаунчером

| Пульт | Действие |
|---|---|
| Стрелки, ОК | выбрать и открыть приложение |
| Удерживать ОК или кнопка «Меню» | в избранное, сдвинуть влево/вправо, скрыть, о приложении, удалить |
| «Назад» / «Домой» на главном экране | вернуться к началу |

Внизу — плитки **Настройки**, **Сеть** и **Скрытые** (вернуть скрытые приложения).

Почему не тормозит: ни одной библиотеки; иконки грузятся в фоне один раз; фон — одна заранее
нарисованная картинка; нет рекомендаций, рекламы, сетевых запросов и фоновых служб;
анимация фокуса делается видеокартой без перерисовки.

## Если что‑то пошло не так

* **Нет главного экрана / чёрный экран** — запустите `restore-tv`, он всё включит обратно.
* **Кнопка «Домой» всё ещё открывает старый экран** — у вашей модели свой лаунчер, которого нет в списке.
  Пришлите модель ТВ и файл `backup/packages-before.txt` — допишу нужные пакеты.
* **Ошибка `INSTALL_FAILED_UPDATE_INCOMPATIBLE`** при повторной установке новой сборки —
  удалите старую: `adb uninstall io.lite.tvlauncher` и запустите скрипт ещё раз.
